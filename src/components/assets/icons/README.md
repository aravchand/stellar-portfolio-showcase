# Technology Icons

This folder should contain SVG or PNG icon files for the following technologies:

## Required Icons

1. **python.svg** - Python logo
   - Source: https://www.python.org/community/logos/
   - Or: https://simpleicons.org/icons/python.html

2. **cpp.svg** - C++ logo
   - Source: ISO C++ Foundation (CC0/public domain)
   - Or: https://simpleicons.org/icons/cplusplus.html

3. **dart.svg** - Dart logo
   - Source: https://dart.dev/brand
   - Or: https://simpleicons.org/icons/dart.html

4. **flutter.svg** - Flutter logo
   - Source: https://flutter.dev/brand
   - Or: https://simpleicons.org/icons/flutter.html

5. **swift.svg** - Swift logo
   - Source: https://swift.org/logo/
   - Or: https://simpleicons.org/icons/swift.html

6. **kotlin.svg** - Kotlin logo
   - Source: https://kotlinlang.org/docs/trademarks.html
   - Or: https://simpleicons.org/icons/kotlin.html

7. **unity.svg** - Unity logo
   - Source: Unity Brand Guidelines
   - Or: https://simpleicons.org/icons/unity.html

8. **ios.svg** - iOS/Apple logo
   - Source: Apple Marketing Resources
   - Or: https://simpleicons.org/icons/apple.html

9. **android.svg** - Android logo
   - Source: Android Brand Guidelines
   - Or: https://simpleicons.org/icons/android.html

10. **meta-xr.svg** - Meta XR logo
    - Source: Meta Brand Resources
    - Or: Use a generic VR/AR icon

11. **latex.svg** - LaTeX logo
    - Source: https://www.latex-project.org/
    - Or: https://simpleicons.org/icons/latex.html

12. **nist.svg** - NIST logo
    - Source: NIST Brand Guidelines

13. **tensorflow.svg** - TensorFlow logo
    - Source: TensorFlow Brand Assets

14. **mediapipe.svg** - MediaPipe logo
    - Source: Google MediaPipe Brand Resources

15. **arduino.svg** - Arduino logo

16. **fusion360.svg** - Fusion 360 logo
    - Source: Autodesk Brand Assets

## Quick Download Option

You can download all icons at once from:
- **Simple Icons**: https://simpleicons.org/ (MIT License, SVG format)
- **DevIcons**: https://devicon.dev/ (MIT License)
- **IconDuck**: https://iconduck.com/ (various licenses)

## File Format

- Preferred: SVG (scalable, small file size)
- Alternative: PNG (transparent background, 256x256px or higher)

## Naming Convention

All files should match the import names exactly (case-sensitive):
- python.svg
- cpp.svg
- dart.svg
